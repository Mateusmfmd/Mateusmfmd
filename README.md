## Tecnologias

`Python` · `JavaScript` · `TypeScript` · `Node.js` · `Java` · `PHP` · `SQL` · `C++/Arduino` · `React` · `React Native/Expo` · `Flask` · `Docker` · `Git/GitHub`

### Competências demonstradas

- **Mobile:** React Native e Expo com formulários, armazenamento local, voz, mapas, geolocalização e upload de imagens.
- **Backend e APIs:** Flask/MVC, CRUD, consumo de APIs, Node.js, TypeScript, PHP e testes.
- **Dados:** SQL/MySQL, SQLite, modelos relacionais, filtros, CSV e GeoJSON.
- **Infraestrutura:** Docker, Docker Compose e GitHub Actions.
- **Hardware:** Arduino, C++, sensores, botões e comunicação serial.
- **Produto:** SaaS, autenticação, estados offline, regras de negócio e evolução de MVPs.
